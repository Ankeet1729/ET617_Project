This image shows the code for both the "Fire" and "Earth" sprites, demonstrating an interactive simulation. The "Fire" sprite's code uses a forever loop to constantly check the microphone's loudness. If a user blows into the mic, making the loudness greater than 30, the fire's size decreases. Once the fire shrinks to a size less than 5, it hides and broadcasts a "heat gone" message. The "Earth" sprite listens for this message and then switches its costume from "sad" to "happy".
